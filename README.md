# Nike React Presentation Website

Ce projet est un site web de présentation pour la marque **Nike**, réalisée dans un objectif éducatif pour maîtriser les technologies **React** et **Tailwind CSS**. Le site met en valeur les produits de la marque Nike tout en offrant une expérience utilisateur moderne et fluide. Ce projet a été conçu pour approfondir mes compétences en développement front-end, en particulier dans l'intégration de **React** avec **Tailwind CSS** pour créer des interfaces réactives et élégantes.

## Fonctionnalités

- **Page d'accueil dynamique** : Mise en avant des produits et des offres spéciales avec une navigation fluide.
- **Design responsive** : Le site s'adapte parfaitement à toutes les tailles d'écran, garantissant une expérience utilisateur optimale sur desktop, tablette et mobile grâce à l'utilisation de **Tailwind CSS**.
- **Structure modulaire** : Organisation du code en composants React réutilisables pour une maintenance facilitée et une évolutivité accrue.

## Technologies utilisées

- **React** : Bibliothèque JavaScript pour construire des interfaces utilisateurs interactives et dynamiques.
- **Tailwind CSS** : Framework CSS utilitaire permettant de créer des designs modernes et réactifs de manière rapide et flexible.
- **React Router** : Gestion de la navigation entre les différentes pages du site.
- **React Icons** : Intégration d'icônes vectorielles pour un design cohérent et moderne.

## Objectif éducatif

Ce projet a été réalisé pour renforcer mes compétences en **React** et **Tailwind CSS**, dans le cadre de mon apprentissage des meilleures pratiques en matière de développement web moderne. L'objectif principal était d'approfondir la gestion des composants React et l'utilisation de Tailwind CSS pour un développement rapide et efficace tout en maintenant une grande flexibilité dans la conception de l'interface.
